## 📖 Overview

The **Spotify-Style Music App** is a modern music streaming web application inspired by Spotify's design and functionality. Built entirely using **Google Antigravity IDE** with AI-assisted development, this app features a curated collection of music tracks sourced from **YouTube Studio** and **Cloudinary**. The application provides an immersive, responsive music streaming experience with playlist management and audio playback controls.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎵 **Song Playback** | Play, pause, skip songs with a built-in audio player |
| 📋 **Playlist Management** | Create and manage personal playlists |
| 🎤 **Song Library** | Browse curated collection of music tracks |
| 🔍 **Music Search** | Search songs by title or artist |
| 📱 **Responsive Design** | Fully optimized for desktop, tablet, and mobile |
| ⚡ **Smooth UI** | Spotify-inspired interface with dark theme |
| 🎧 **Audio Controls** | Volume control, progress bar with seeking |

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- **Node.js** (v14 or higher)
- **npm** or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/UradiSrilekha/Spotify.git
   cd Spotify
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Configuration

1. Create a `.env` file in the root directory:
   ```env
   PORT=5000
   NODE_ENV=development
   CLOUDINARY_URL=your_cloudinary_url
   ```

2. **Music URLs**: Add your Cloudinary and YouTube Studio audio links in the music configuration file (e.g., `data/music.js` or backend database)

### Running the App Locally

1. **Start the development server:**
   ```bash
   npm start
   ```

2. Open your browser and navigate to "https://6a292df1cb925b8a93ff3d0d--singular-narwhal-5d4796.netlify.app/"
